# BarberosControl — Landing

Landing page estática (un solo archivo `index.html`, sin build, sin frameworks). Reemplaza al proyecto React anterior.

## Estructura

- `index.html` — página completa (HTML + CSS + JS inline)
- `assets/images/` — logos de clientes, foto de BarberClub, imagen de Open Graph

## Deploy

Sitio 100% estático. No requiere `npm install` ni build. Configurado para Vercel vía `vercel.json` (sirve los archivos del repo tal cual).
